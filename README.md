# Vaccination Tweet Sentiment & Stance

Research code for reproducible, model-assisted analysis of historical vaccination-related tweets (2006–2019).

**Data policy:** The source corpus, raw tweet text, original archives, model weights, credentials and annotation outputs are not committed here. Keep those in controlled project storage. This public repository contains code, schemas, and synthetic tests only.

**Status:** Initial benchmark implementation is staged on a feature branch. Historical research outputs remain independent and immutable.

See the feature branch and its pull request for setup and methodology when available.
