# Sources and references

**Updated:** 5 November 2026. Sources are separated into external scholarly/model materials and actual project execution evidence. A model's published benchmark, a green Actions run and an independently validated result are three different kinds of evidence.

## Scientific and model references

1. Barbieri F, Camacho-Collados J, Espinosa Anke L, et al. **TweetEval: Unified Benchmark and Comparative Evaluation for Tweet Classification.** Findings of EMNLP 2020. [ACL Anthology](https://aclanthology.org/2020.findings-emnlp.148/). Methodological background for Twitter-specific classification benchmarks.
2. Barbieri F, Espinosa Anke L, Camacho-Collados J. **XLM-T: Multilingual Language Models in Twitter for Sentiment Analysis and Beyond.** LREC 2022:258–266. [Paper](https://aclanthology.org/2022.lrec-1.27/) | [XLM-T sentiment model](https://huggingface.co/cardiffnlp/twitter-xlm-roberta-base-sentiment). Multilingual sentiment model rationale.
3. Loureiro D, Barbieri F, Neves L, Espinosa Anke L, Camacho-Collados J. **TimeLMs: Diachronic Language Models from Twitter.** ACL System Demonstrations 2022:251–260. [Paper](https://aclanthology.org/2022.acl-demo.25/) | [Twitter-RoBERTa latest](https://huggingface.co/cardiffnlp/twitter-roberta-base-sentiment-latest). English tweet sentiment and temporal domain shift.
4. Laurer M et al. **Building Efficient Universal Classifiers with Natural Language Inference.** [arXiv:2312.17543](https://arxiv.org/abs/2312.17543) | [DeBERTa zero-shot classifier model card](https://huggingface.co/MoritzLaurer/deberta-v3-large-zeroshot-v2.0). General NLI classification, not vaccine-stance-specific validation.
5. Qwen Team. **Qwen3 Technical Report.** 2025. [Paper](https://arxiv.org/abs/2505.09388) | [Qwen3-4B-Instruct-2507 model card](https://huggingface.co/Qwen/Qwen3-4B-Instruct-2507). Large language model used in capped semantic ontology experiments.
6. Mu Y, Jin M, Grimshaw C, Scarton C, Bontcheva K, Song X. **VaxxHesitancy: A Dataset for Studying Hesitancy Towards COVID-19 Vaccination on Twitter.** Proc ICWSM 2023;17:1052–1062. [Zenodo V2, DOI 10.5281/zenodo.7601328](https://zenodo.org/records/7601328). Independently labeled reference; the inspected files carried tweet IDs/annotations rather than directly usable tweet text.
7. Kummervold and colleagues. **VACMA-PUBLIC**, associated with *JMIR Medical Informatics* 2021, article e29584. [Public source repository](https://github.com/peregilk/VACMA-PUBLIC) | [Journal article](https://medinform.jmir.org/2021/10/e29584/). Text-bearing published *vaccination intention* proxy, not the project's six-category author-stance ground truth.
8. [Kaggle public API documentation](https://www.kaggle.com/docs/api) and [GitHub Actions documentation](https://docs.github.com/en/actions). Software/infrastructure references, distinct from evidence of completed private inference.
